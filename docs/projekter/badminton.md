# 🏸 Badminton Manager

Velkommen til dokumentationen for min personlige Badminton Manager. Dette program kører i mit **KJP-Lab** på Debian 13 (Trixie) og hjælper med at holde styr på statistikker mod klubbens spillere.

## 📊 Funktioner
* **CSV-drevet:** Indlæser og gemmer kampresultater automatisk i `kampe.csv`.
* **Interaktiv menu:** Gør det nemt at registrere point og modstandere direkte fra terminalen.
* **Flotte tabeller:** Bruger `tabulate` til at spytte statistikker ud live.

## 🚀 Fremtidige udvidelser
